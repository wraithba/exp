# Simple Flutter Lab: Experiments 1-10

Ten independent study samples for Kevin. Each folder contains lib/main.dart, abc.txt, pubspec.yaml and README.md. No screenshots, PDFs, build output or generated platform files are bundled.

Basic Flutter controls are retained because these are Flutter experiments; there is no elaborate interface. Each README contains a simple idea, aim, exactly 12 description points, setup, expected checks, result and scope. These are small teaching samples, not complete replicas of the original records. Check the scope section against your exam question.

Start with each experiment's README. Experiments 1-5 run on Windows desktop, Linux desktop or Chrome. Experiment 6 runs on Windows/Linux desktop using SQLite FFI (not Chrome). Experiments 7-10 run in Chrome on Windows or Linux and need your real Firebase project and generated options. Each README contains OS-specific instructions. Native Linux Firebase execution is not included. Experiment 10 uses Firebase Authentication rather than the record's manual password-hash comparison. There is no fake local cloud fallback.

Flutter and Dart were not available during authoring. These samples have not been compiled or run; dependency resolution and Firebase/device behavior must be checked on your computer.
